# Lessons for the conversion skill

| Observation from this campaign | Transferable change to the workflow |
| --- | --- |
| The first direct workflow read inclusive particle-flow energy density. The small-radius calibration actually requested the neutral density. Both branches exist and have the same type. | Record the initialized data-handle key alongside the physical ROOT branch and its type. Check the first differing intermediate against the named input before modifying a numerical kernel. |
| A valid large-radius mass-resolution table has a repeated first bin edge. Other tables carry an active ROOT axis range, which changes a projection. | Include persisted axis flags, ranges and real duplicate-edge examples in the calibration-file inventory. Compare the original object's behavior on boundaries and in projections before converting its storage. |
| The original C++ JSON reader changed nine binary64 EtaJES coefficients. Twenty-seven small-radius masses differed slightly after four-vector reconstruction. | Keep a small decimal-to-binary64 reproduction and an independent full-sample stage test. Tiny changes to a coefficient can become visible after subtracting nearly equal squares. |
| The two original jet packages have slightly different three-dimensional interpolation conventions. The shared implementation needed two explicit entry points. | Trace the caller into the helper actually linked by the release. A common mathematical name does not determine boundary or rounding behavior. [Fixture](evidence/diagnostics/portable-histogram.txt) |
| The original observer emitted both object-level quantities and duplicate public output names. A passing 6,277-field comparison did not account for all 7,189 names. | Reconcile the actual ROOT key set against the field map. Show which outputs are checked directly, which are derived, and which are aliases. Preserve the difference between an absent status and a present out-of-validity flag. |
| A single assigned CPU still allowed uproot to create worker threads. ROOT startup also spawned short-lived sequential helper programs. | Record process affinity, thread count and whether child processes survived into event processing. Configure synchronous reading explicitly and retain a clean, successful reference process. |
| The combined stock pilot accumulated 131 seconds of I/O wait on its assigned CPU. Its two histograms still matched the separate jobs. | Verify physics agreement and timing quality separately. Retain CPU time, per-CPU I/O wait, file size and interleaved measurements before assigning a combined-workflow speedup. |
| During excluded warm-ups a new dormant option changed the live Python file's bytes. A running shell build also encountered an edited metadata tail after all seven libraries had linked. | Freeze the actual entry script and local imports for a cohort, and snapshot a shell build driver at launch. Preserve the original attempt and independently verify any completed binaries before recovering just the missing metadata. [Warm-up source audit](evidence/timing/faithful/warmup-source-audit.json) |
| The small-R analysis asked for the same positive-seed Gaussian millions of times, but four first variates produced a negative scale. | Count production fallbacks separately from cache hits, validate rejection ordering in a stock fixture, and allocate a distinct instrumented provider so the timed binary carries no counters. [Production counts](evidence/diagnostics/cache-use/small.json) |
| Two single-radius CorrectionSets were byte-exact projections of the combined file. A user-facing package still had to reconstruct its selected file before loading it. | Time the installation's actual materialization, record the bytes and digest produced, and distinguish compressed archive size, scratch space, process RSS and parsed document size. [Storage comparison](evidence/diagnostics/scope-wheel-bytes.json) · [Large-R startup observations](evidence/diagnostics/scope-wheel/startup-large.json) |
| The source stores a separate energy branch for 117 small-R states. A compositional proof established its correctness before a plot existed for it. | Inventory derived analysis outputs before plotting. Fill the stock histogram from the persisted branch and the converted histogram from the candidate's own evaluated four-vector, then check both the individual values and the bins. |
| Single-radius startup depends on which CorrectionSet the installed script constructs. The first small-R construction series and large-R canonical series exceeded the spread limit. A fresh comparison of just the two deployable choices passed all four spread checks. | Include the actual on-demand write and its peak RSS in the shipped endpoint. For a bounded repeat, preserve the original stock archive, record the selected payload's hash, and rerun the two choices that decide the default. [Small-R](evidence/diagnostics/loading-repeat/small.json) · [Large-R](evidence/diagnostics/loading-repeat/large.json) |
| Interpolation and ordinary flow classification both ended in the same compiled double-precision lower-bound routine. Replacing a flow test left fewer than half those samples available to an irregular-axis search change. | Attribute a repeated native leaf to its inlined caller before estimating an optimization ceiling. Check the actual tables for repeated edges, active ranges and very unequal bin widths before choosing a lookup algorithm. [Within-tool stacks](evidence/diagnostics/packed-native/within_owner_inclusive.tsv) |
| AnalysisBase and direct Python enter the same large-R truth-matching node. Only the direct caller owns the truth data long enough to reuse a match across states. The full framework still computes a three-output selection twice where two algorithms reach the same jet. | Record the lifetime and identity of each adapter's actual inputs alongside the shared node name. For a multiple-output result, count which callers consume each output and which can legally reuse it. [Framework call-site audit](evidence/diagnostics/framework-execution.json) |
| The native profile located array operations but could not establish which copy was optional. The Python profile resolved 129,220 flatten calls to the installed evaluator. The native binding releases the GIL. | Pair native stacks with direct Python callers before changing array transport. Establish ownership, snapshot semantics and execution-thread guarantees before interpreting an apparently redundant copy as removable. [Python call profile](evidence/final/python-profile/summary.txt) |
| The two single-radius stock outputs contained exactly the combined output's 1,010 branches. ROOT output size was nearly additive even though direct C shared seven physical input leaves. | Verify the union of persisted outputs and the input branch intersection separately. Use the release's filtered systematic lists and observed call counts to interpret joint timing. [Joint framework output and filtering](evidence/diagnostics/joint-framework-scope.json) |
| The 0.493 s stored-only Python control finished before the observer's second library-map sample. It processed its whole input, but the external record could not prove the bundled compiler libraries. | Exercise the shortest control with the same runtime-evidence checks as the slowest job. Sample maps at existing startup observations and verify the sampling change using a subsecond process that loads the real libraries. Give the revised controller a fresh timing journal. [Rejected launch](evidence/timing/production/monitor-001/stored-control-rejection.json) · [Observer patch and fixture](evidence/source/production-timing.patch) |
| The nominal histogram stores its one state name as five Unicode characters. A view of the same label from the full state array retains room for its longest label. | Check state label values, order and array shape independently of the string column's storage width. Keep byte-level comparisons for numerical histograms, including signed zero where promised. [Selected scoped framework receipts](evidence/final/recovered-small/recovery.json) |
| The completed grid had 265 exact histogram comparisons and stable global stock anchors. Small-R nominal B/A still exceeded a spread limit first in B and then in A on its sole paired recheck. | Track the quality of the legs used by each decision. Preserve the original and bracketed observations and the paired range even when all ratios lie below the budget. Report a decision as unresolved if its bounded recheck still fails the frozen spread rule. [Full grid](evidence/timing/production/summary.json) · [Bounded recheck](evidence/timing/recheck-AB-small-nominal-001/summary.json) |
