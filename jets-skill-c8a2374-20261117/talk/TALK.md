# Can Both Jet Sizes Use the Same Calibration Code?

This technical working-group talk assumes a 12-minute slot for ATLAS colleagues who know jets and systematic variations and may be new to CorrectionLib.

Gordon's speaker profile guides the writing. Start from what an analyst reads and measures. Introduce CorrectionLib as a way to distribute calibration data together with a graph of numerical operations. Use the release calibration as the independent authority throughout.

The audience should leave able to explain which calculations the two collections share, how we checked them on actual jets, and why reading both collections together saves time for the direct command. In the matched production grid the combined script saved 1.35 s per 20,000 events. The converted framework took 11.2% longer jointly, with nearly additive ntuple output. The main example is the weighted small-radius and selected large-radius transverse-momentum histogram on the same PHYSLITE file.
