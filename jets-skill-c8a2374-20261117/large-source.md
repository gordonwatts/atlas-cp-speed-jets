## Numerical contracts to preserve

**EtaJES.** `SetDetectorEta=false` preserves the stored float detector eta. `JetCalibrationStep::setStartP4` writes the named `JetConstitScaleMomentum` back through xAOD before the tool reads its vector. The nominal global TEnv names the JES constants and ROOT response under versioned `CalibrationFactors`. The constants enter as a local TEnv read. The selected spline route takes the reciprocal of TH1 interpolation in energy in GeV, using the signed detector-eta bin of the `etaJes` TList. At `E/cosh(DetectorEta)` below 50 GeV, it extends the response linearly from the bin's threshold energy based on its lower eta edge and the slope between adjacent histogram centers. The eta correction is a separate negative log-polynomial using scaled energy clamped to `[8*cosh(DetectorEta), 2500]` GeV. The stage reconstructs the direction via TLorentzVector with `P/cosh(corrected eta)`, writes `JetEtaJESScaleMomentum`, and installs the current p4. [EtaJES source](https://gitlab.cern.ch/atlas/athena/-/blob/6ce3f7ae7c41dd9eaec170c3c349df15faef7e5c/Reconstruction/Jet/JetCalibTools/Root/EtaJESCorrection.cxx#L226)

**Nominal JMS.** This active recipe reads the EtaJES vector after stage writeback, requires nonzero mass and `abs(DetectorEta)` below the final z edge, and queries the TH3F named `AntiKt10UFOCSSKSoftDropBeta100Zcut10_JMS_e_LOGmOe_eta` using `(E/1000, log(m/E), abs(DetectorEta))` with a positive ratio. The helper uses inside-edge offsets of `1e-6`, returns one for a NaN logarithm, and bypasses values at or below 180 on its first axis. That axis is energy in this recipe, despite the configuration key `MinpT`. Round the response and corrected mass to float at their source assignments. A zero factor becomes one, and a corrected mass greater than energy is replaced by the original mass. Default `pTfixed=false` recomputes pT at fixed energy and direction before the tool rebuilds and writes `JetJMSScaleMomentum`. The xAOD storage boundary preserves float pT, eta, phi and mass, even though accessors carry them into double computations and derive energy from the reconstructed p4. The nominal config sets the time-dependent in-situ flag, so the initializer can still read the event run number on MC. The in-situ config files and numerical steps require an `Insitu` sequence. [JMS interpolation](https://gitlab.cern.ch/atlas/athena/-/blob/6ce3f7ae7c41dd9eaec170c3c349df15faef7e5c/Reconstruction/Jet/JetCalibTools/Root/JMSCorrection.cxx#L299) · [JMS application](https://gitlab.cern.ch/atlas/athena/-/blob/6ce3f7ae7c41dd9eaec170c3c349df15faef7e5c/Reconstruction/Jet/JetCalibTools/Root/JMSCorrection.cxx#L503)

**Combined JES/JER/JMS.** The file-wide `ValidRange_JMS_<jet definition>` gate uses ordinary noninterpolated bins in nominal `(pT, Calo mass, signed eta)` and runs even at NOSYS. The validity and component code prefer the calibrated Calo p4 attribute if available and fall back to the current p4 for Calo. For the normal uncertainty response, the configuration supplies Pt, PtEta, PtAbsEta, PtAbsMass or eLOGmOeAbsEta, with the ordinary histogram helper distinguishing full interpolation from `OnlyX` and noninterpolated bin selection. The active range handler clamps underflow to the first low edge and overflow to the last low edge plus 0.999 times its width. The separate float boundary helper in the same file is outside this call path. The source separately applies grouped linear or quadrature combination, variation parameters, and truth-label filters. `FourVec` shifts pT and mass, `Mass` holds pT fixed, and the configured absolute `PtResAbs` JER shifts pT with mass fixed. Reconstruct energy from the resulting p4. Full JER looks up `JER_Nominal_R10_Both` for both MC and (pseudo-)data with `PtAbsEta,OnlyX`. The sign of the evaluated signed shift decides whether the MC or pseudo-data side smears. The Gaussian width is `sqrt((sigmaNom + abs(delta))² - sigmaNom²)` for absolute variations with `sigmaNom=max(sigmaMC,sigmaData)`. The default `TRandom3` seeds are truncated `2e5*abs(phi)` on MC and `1.23e5*abs(phi)` on pseudo-data, with respective zero fallbacks `45583453` and `34545654`. The tool redraws negative factors. [Validity and application](https://gitlab.cern.ch/atlas/athena/-/blob/6ce3f7ae7c41dd9eaec170c3c349df15faef7e5c/Reconstruction/Jet/JetUncertainties/Root/JetUncertaintiesTool.cxx#L2091) · [Smearing](https://gitlab.cern.ch/atlas/athena/-/blob/6ce3f7ae7c41dd9eaec170c3c349df15faef7e5c/Reconstruction/Jet/JetUncertainties/Root/JetUncertaintiesTool.cxx#L2481)

**JMR forward folding.** The active config sets `doGaussianSmearing=false`. The input to JMR is the nominally calibrated p4 propagated for that FF state. Reject `abs(eta)>2`, `m>600000 MeV`, `pT>5000000 MeV`, nonpositive mass, and a missing truth match as out of validity. The closest truth p4 within strictly `ΔR<0.75` wins after casting each distance to float, with input order breaking ties. A missing topology decoration is an error. A stored no-truth label is out of validity. The topology and mass-definition gates can leave a valid jet unchanged. The response TH2 key is `ResponseMaps/QCD_Calo_AvgMassResponse_vs_recopt_vs_truthm_smoothed_rebinned`. Its inputs are reco pT and matched truth mass in GeV. An out-of-map lookup returns zero and the caller substitutes one. The `PtAbsMass` uncertainty uses float-converted GeV coordinates and returns zero outside the TH2. The `eLOGmOeAbsEta` variant uses a TH3F with inside-edge offsets of `1e-6` and handles a NaN logarithm as zero. The UFO formula is `m*scale + (m - response*m_truth)*(resolution - scale)` with the signed JMR error entering resolution and a `1e-4` no-change threshold. Write back p4 with unchanged pT, eta and phi and the new mass. The source reads a potentially uninitialized TA local in an inactive-weight fallback after the UFO calculation. The UFO final mass branch uses `smeared_UFO_mass` directly. Treat this as a source-level hazard pending original-tool edge/status checks. ## Shared implementation opportunities

Small-R and large-R use the same pre-jet adapter and lookup infrastructure, `CP::JetCalibrationAlg` / `JetCalibrationTool` entry point and EtaJES class, and `CP::JetUncertaintiesAlg` / `JetUncertaintiesTool` dispatcher, uncertainty groups, histogram helpers and JER RNG. Their physics configurations and input coordinates differ. Small-R EMPFlow has pile-up, residual, GSC, and NNJVT-related calls. Large-R adds nominal JMS, separate JMR forward folding with event truth-jet input, and calibrated pT, rapidity and mass cuts. Share the four-vector and float-writeback primitive, bin selection, interpolation with explicit boundary policy and singleton handling, log-polynomial evaluation, signed grouped variations and the original JER RNG. Make JMR a separate callable stage. Support the nominal JMS constant-energy rebuild and FF mass-only update as distinct operations. Cache the nominal jet vector, global validity where the input is identical, and JMR truth-match/response preparation across FF states only when their kinematic and topology dependencies agree. These are implementation candidates from source inspection.
